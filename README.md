# Jaivin — Reference-Inspired React Portfolio

A React + Vite portfolio adapted from the supplied Siva Doom reference source, with its futuristic dual-theme interface, animated HUD styling, scroll transitions, interactive project gallery, project inspection modals, and terminal-style interaction.

## Personalised sections
- Home / hero
- About and education
- Skills and interactive terminal
- Projects: School Website, CRM Dashboard, AI Cooking Assistant
- Experience & growth
- Contact

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

## Verify production build
```bash
npm run build
npm run preview
```

## Important
- Project descriptions are portfolio concepts; verify and edit them before publishing.
- The contact form requires your own `WEB3FORMS_ACCESS_KEY` or `RESEND_API_KEY`; copy `.env.example` as a guide and configure secrets in your hosting provider. No reference-project API key is included.
- The resume is served from `public/resume.pdf`. Replace it with the latest approved resume before publishing.
- Social profile URLs are left blank where they were not provided.
